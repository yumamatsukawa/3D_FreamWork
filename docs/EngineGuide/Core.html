    3D_FreamWork の Engine を、初心者向けに解説したページです。

    Core(基本の仕組み)

    Engine/Core/ は、ゲームの土台です。「物(GameObject)に部品(Component)を付けて、シーン(Scene)に置く」という Unity と同じ考え方の中心がここにあります。時間・入力・計算・使い回し・通知など、どのゲームでも使う小さな道具もここに入っています。 最初に読むなら、Component → GameObject → Scene → SceneManager の順がおすすめです。

    Engine/Core/Component.h

    すべての Component の親クラス(基底クラス)。Unity の MonoBehaviour に近い役割です。動きや見た目は、これを継承したクラスを作って Init / Update / Draw などを override(上書き)して書きます。

    名前引数・戻り値何をするか
    Init()void (virtual)AddComponent で追加された直後に、1回だけ呼ばれる。初期設定を書く所
    Update(float dt)void (virtual)毎フレーム呼ばれる(ロジック更新)。dt は前のフレームからの秒数
    Draw()void (virtual)毎フレーム呼ばれる(描画)
    Uninit()void (virtual)GameObject が破棄される時に呼ばれる。後片付けを書く所
    OnActiveChanged(bool active)void (virtual)GameObject::SetActive が呼ばれた時の通知。ObjectPool で使い回す物の検知に使う
    OnTriggerEnter(Collider2D* other)void (virtual)すり抜ける当たり判定(トリガー。2D・3D 共通)に「入った瞬間」
    OnTriggerStay(Collider2D* other)void (virtual)トリガーに「入っている間」毎フレーム
    OnTriggerExit(Collider2D* other)void (virtual)トリガーから「出た瞬間」
    OnCollisionEnter(CollisionInfo info)void (virtual)すり抜けない当たり判定(衝突。2D・3D 共通)で「ぶつかった瞬間」
    OnCollisionStay(CollisionInfo info)void (virtual)「ぶつかっている間」毎フレーム
    OnCollisionExit(CollisionInfo info)void (virtual)「離れた瞬間」
    GetOwner()GameObject*この Component が付いている GameObject を返す
    SetOwner(GameObject* go)void持ち主を設定する(AddComponent が自動で呼ぶ。普段は使わない)
    IsEnabled()bool有効か(無効だと Update / Draw が呼ばれない)
    SetEnabled(bool v)void有効 / 無効を切り替える
    使い方の例 出典: Sample2D/Game/Components/BulletController.cpp:5-23
    void BulletController::Update(float dt) {
    Transform& t = GetOwner()->transform;

    // まっすぐ進む(Kinematicなので位置を直接動かしてよい)
    t.position.x += direction.x * speed * dt;
    t.position.y += direction.y * speed * dt;

    // 寿命が来たらプールに返す
    if (lifeTimer.Update(dt) && pool) {
        pool->Return(GetOwner());
    }
}

void BulletController::OnTriggerEnter(Collider2D* other) {
    // 敵に当たったら消える(プールに返す)
    if (other->GetTag() == "Enemy" && pool) {
        pool->Return(GetOwner());
    }
}
    気を付ける点
    • Init は AddComponent の中で呼ばれます。AddComponent の戻り値をまだ受け取っていない時点で Init が動くので、「作った直後に他の Component を設定する」処理は AddComponent の後に書きます。
    • 他の Component の情報が必要な時は、GetOwner()->GetComponent<型>() で探します。見つからないと nullptr なので、必ずチェックします。

    Engine/Core/GameObject.h

    「入れ物」です。名前・タグ・位置(transform)を持ち、Component を付けて見た目や動きを作ります。Unity の GameObject と同じです。Scene::CreateObject で作り、Destroy() で消します。

    名前引数・戻り値何をするか
    transformTransform (メンバ変数)すべての GameObject が必ず持つ位置・大きさ・回転
    AddComponent<T>(args...)T*Component を作って付ける。引数は T のコンストラクタへ渡る。付けた直後に Init() が呼ばれる
    GetComponent<T>()T*付いている T 型(派生クラスも含む)の Component を探す。無ければ nullptr
    GetName()const std::string&名前を返す
    GetTag()const std::string&タグを返す("Player" や "Enemy" など。当たった相手の判定に使う)
    SetTag(std::string t)voidタグを付ける。ObjectPool の組み立て処理の中で使う
    SetActive(bool v)voidfalse で非表示・Update/Draw 停止(破棄はされない)。全 Component に OnActiveChanged が届く
    GetIsActive()bool有効か
    Destroy()void「破棄する」印を付ける。実際に消えるのは次の Scene::Update の終わり
    GetIsDestroyed()boolDestroy() が呼ばれたか
    GetScene()Scene*自分が属している Scene。Component の中から新しい物を作りたい時に使う
    SetScene(Scene* s)void属する Scene を設定する(Scene::CreateObject が自動で呼ぶ。普段は使わない)
    GetDrawPriority()int描画順の優先度を返す
    SetDrawPriority(int priority)void描画順。小さいほど先に描かれる(既定0)。スカイボックスや背景に使う
    Update(float dt)void持っている全 Component を更新する(Scene が呼ぶ。普段は使わない)
    Draw()void持っている全 Component を描く(Scene が呼ぶ。普段は使わない)
    Uninit()void全 Component の Uninit を呼ぶ(Scene が呼ぶ。普段は使わない)
    OnTriggerEnter など6個void当たり判定のコールバックを全 Component に転送する(Collider が呼ぶ。普段は使わない)
    使い方の例 出典: Demo/Game/Objects/Core/TransformDemo.cpp:16-25
    GameObject* parent = scene.CreateObject("Parent");
parent->transform.scale = { parentSize, parentSize, is3D ? parentSize : 1.f };
if (is3D) {
    parent->transform.position = { 0.f, 0.f, 300.f };
    parent->AddComponent<MeshRenderer>(Mesh::CreateCube())->SetColor(0.4f, 0.6f, 0.9f, 1.0f);
}
else {
    parent->transform.position = { 0.f, -20.f, 0.f };
    parent->AddComponent<SpriteRenderer>(L"Assets/box.png", 3, 3)->SetSpriteIndex(5);
}
    使い方の例 出典: Sample2D/Game/Components/PlayerController.cpp:25-27
    Transform& t = GetOwner()->transform;
SpriteRenderer* renderer = GetOwner()->GetComponent<SpriteRenderer>(); if (!renderer) return;
RigidbodyComponent* rigidbody = GetOwner()->GetComponent<RigidbodyComponent>(); if (!rigidbody) return;
    気を付ける点
    • GetComponent の結果は 必ず null チェック します(付いていない場合は nullptr が返ります)。
    • SetActive(false) は消すのではなく「お休み」です。完全に消す時は Destroy()。
    • Destroy() はその場では消えません。同じフレームの残りの処理では、まだ使えます。
    • drawPriority は描画の順番だけを決めます。UI モードのスプライトは、drawPriority → 作った順で、ワールドの物より必ず手前に描かれます(詳しくは設計図の描画の順番)。

    Engine/Core/Scene.h Engine/Core/Scene.cpp

    GameObject を入れておく入れ物です。Unity の Scene に相当します。ゲームの画面(タイトル・プレイ画面など)ごとに Scene を継承したクラスを作り、Init() に「何を置くか」を並べます。

    名前引数・戻り値何をするか
    Init()void (virtual)シーンが始まる時に1回呼ばれる。ここで CreateXxx(*this) を並べてオブジェクトを置く
    Uninit()void (virtual)シーンが終わる時に1回呼ばれる。override した時は最後に Scene::Uninit() を呼ぶ
    Update(float dt)void全 GameObject を更新し、Destroy された物を片付け、Update 中に作られた物を加える(SceneManager が呼ぶ)
    Draw()void3パスで描画する(SceneManager が呼ぶ。描画の順番参照)
    CreateObject(std::string name, std::string tag)GameObject*新しい GameObject を作ってシーンに加える。Update 中に呼んでもよい
    使い方の例 出典: Sample2D/Game/Scenes/GameScene.cpp:15-36
    void GameScene::Init()
{
    // オブジェクトを配置するだけ(動き・ルールは各Componentに書く)
    CreateBackground(*this);
    GameObject* player = CreatePlayer(*this);
    CreateWall(*this, { -250.0f, 150.0f }, { 40.0f, 300.0f });   // 見張り役とPlayerの間の壁
    CreateWall(*this, { 400.0f, -350.0f }, { 300.0f, 40.0f });
    CreateGuard(*this, player);
    GameManager* gameManager = CreateGameSystem(*this);
    NavGridComponent* navigation = CreateNavigation(*this);   // 壁をすべて置いた後に置く(敵が壁を避けるための格子)
    CreateEnemySpawner(*this, player, navigation);
    CreateBulletSpawner(*this);
    CreateHUD(*this, gameManager, player->GetComponent<PlayerController>());
}

void GameScene::Uninit()
{
    // 各ManagerがEventBusに登録した処理を消す(残すと、破棄済みのオブジェクトを触ってしまう)
    EventBus::Get().Clear();

    Scene::Uninit();
}
    気を付ける点
    • Update 中に CreateObject しても大丈夫です。作った物は一旦「待ち行列(pendingObjects)」に入り、Update の最後にまとめてシーンへ移ります(ループ中に配列を増やして壊れないように)。そのため、作ったフレームでは Update されません(次のフレームから)。
    • Uninit を override する時は、最後に必ず Scene::Uninit() を呼びます(GameObject の後片付けをするため)。
    • EventBus に this をキャプチャしたラムダを登録した Scene は、Uninit で EventBus::Get().Clear() を呼びます。

    Engine/Core/SceneManager.h Engine/Core/SceneManager.cpp

    今のシーンを持ち、シーンの切り替え(と切り替えの演出)を担当します。アプリ全体で1つだけ(SceneManager::Get())。

    名前引数・戻り値何をするか
    Get()static SceneManager&唯一の SceneManager を返す
    ChangeScene<T>()void演出なしで T 型のシーンへ切り替える(次の SceneManager::Update の最初で切り替わる)
    ChangeScene<T>(transition)void演出付きで切り替える。transition は FadeTransition() や SpriteTransition(...) など
    Update(float dt)void内部用: GameEngine が呼ぶ。切り替えの処理と、今のシーンの Update
    Draw()void内部用: GameEngine が呼ぶ。今のシーンの Draw
    DrawTransition()void内部用: 切り替えの演出を一番上に描く
    Uninit()void内部用: 終了時に今のシーンを片付ける
    使い方の例 出典: Sample2D/Game/Objects/StartButton.cpp:10-14
    GameObject* button = CreateButton(scene, L"START", { 0.f, -150.f }, [] {
    // 黒で0.5秒かけて暗転 → GameSceneへ切り替え → 0.5秒かけて明転
    // (切り替え中にもう一度押されても、SceneManagerが無視するので二重に切り替わらない)
    SceneManager::Get().ChangeScene<GameScene>(FadeTransition());
});
    使い方の例 出典: Sample2D/Game/Components/GameManager.cpp:43-45
    if (gameOver && Input::GetKeyDown(KEY_SPACE)) {
    SceneManager::Get().ChangeScene<TitleScene>(SpriteTransition(L"Assets/transition_circle.png", 8, 2, 0.04f));
}
    気を付ける点
    • 演出付きの切り替えは「覆う → シーンを切り替える → 開く」の順です。演出の間はゲームの時間が止まります(Time の倍率が0)。開き終わると元の倍率に戻ります。
    • 切り替えを頼んでから終わるまでの間に呼ばれた ChangeScene は 無視されます(ボタンの二重押しで2回切り替わらないように)。出力ウィンドウにメッセージが出ます。
    • 切り替える時、古いシーンの Uninit → 新しいシーンの Init → 使っていない画像などの解放(Resources::UnloadUnused)の順で進みます。
    • 内部用の関数(Update / Draw / DrawTransition / Uninit)はゲーム側から呼びません。

    Engine/Core/GameEngine.h Engine/Core/GameEngine.cpp

    エンジン全体を動かす役です。初期化・メインループ(1フレームごとの処理の順番)・終了処理を持ちます。ゲーム側は main.cpp で Init → 最初のシーンを指定 → Run → Uninit を呼ぶだけです。1フレームの順番はトップページにまとめています。

    名前引数・戻り値何をするか
    Get()static GameEngine&唯一の GameEngine を返す
    Init(HWND hwnd, int w, int h)bool画面・音・文字・物理・時間などを初期化する。失敗したら false
    Run()voidメインループ。ウィンドウが閉じられるまで1フレームずつ更新と描画を繰り返す
    Uninit()void終了処理。セーブデータの保存、各機能の解放を正しい順番で行う
    GetScene()Scene&GameEngine 自身が持つ Scene を返す(サンプルでは使っていない。シーンは SceneManager が管理する)
    使い方の例 出典: Sample2D/main.cpp:56-65
    // エンジンの初期化
auto& engine = GameEngine::Get();
engine.Init(hwnd, WINDOW_W, WINDOW_H);

// 最初のシーンの設定
SceneManager::Get().ChangeScene<TitleScene>();

// ゲームループ(ウィンドウが閉じられるまで)と終了処理
engine.Run();
engine.Uninit();
    気を付ける点
    • Run の中の呼ぶ順番には意味があります(例: 物理 → シーンの Update → 音。描画の前にカメラを揺らす、など)。順番を変えるとバグの原因になるので、Engine を触る人以外は変更しません。
    • 初期化の順番も重要です(Image::Init の後に音・文字・物理)。SaveData::Init は最初に呼ばれます。

    Engine/Core/Transform.h

    位置・大きさ・回転と、親子関係を持ちます。Unity の Transform と同じです。GameObject の transform メンバとして必ず付いています。回転は 度 で、2D は rotate.z だけを使います。

    名前引数・戻り値何をするか
    positionXMFLOAT3位置(親がいれば、親から見た相対位置)
    scaleXMFLOAT3大きさ(既定は 1,1,1)。2D のスプライトはこれがピクセルの大きさになる
    rotateXMFLOAT3回転(度)。2D は rotate.z
    SetParent(Transform* newParent)void親を設定する。nullptr で親を外す
    GetParent()Transform*親を返す(無ければ nullptr)
    GetChildren()const std::vector<Transform*>&子の一覧
    GetLocalMatrix()XMMATRIX自分だけの行列(親は考えない)
    GetWorldMatrix()XMMATRIX親をたどった最終的な行列
    GetWorldTransform()Transform親をたどって「ワールドでの位置・大きさ・回転」にした Transform。2D 用(回転は Z 軸だけ合成)
    WorldDeltaToLocal(XMFLOAT2 worldDelta)XMFLOAT2ワールドでの移動量を、position に足せる量に変換する(押し戻しなどで使う)
    使い方の例 出典: Demo/Game/Objects/Core/TransformDemo.cpp:27-34
    // 子(小さい物): 親につなぐ。位置と大きさは、親から見た値になる。自分でもゆっくり回る
GameObject* child = scene.CreateObject("Child");
child->transform.position = childLocalPosition;
child->transform.scale = childLocalScale;
if (is3D) child->AddComponent<MeshRenderer>(Mesh::CreateCube())->SetColor(1.0f, 0.8f, 0.3f, 1.0f);
else child->AddComponent<SpriteRenderer>(L"Assets/box.png", 3, 3)->SetSpriteIndex(2);
child->transform.SetParent(&parent->transform);
child->AddComponent<SpinComponent>(mode, 90.f);
    気を付ける点
    • 子の position は「親から見た位置」です。親を動かすと子も一緒に動きます。
    • GetWorldTransform() は Z 軸回転だけ 親から引き継ぎます(2D 描画用)。3D の親子の回転は GetWorldMatrix() を使います。
    • 親が消える時は、先に SetParent(nullptr) で外すか、親子まとめて扱ってください(親子のポインタが残ると危険です)。
    • PhysX の Dynamic な剛体は、transform を直接書き換えず RigidbodyComponent::SetVelocity() で動かします。

    GetKeyDown(WORD button, int padIndex)boolゲームパッドのボタン版(PAD_A など。padIndex の既定は0)
    GetKeyPress(WORD button, int padIndex)boolパッド版の「押している間」
    GetKeyUp(WORD button, int padIndex)boolパッド版の「離した瞬間」

    GetMouseDelta()XMFLOAT2前のフレームからのマウスの移動量(視点操作に使う)
    SetCursorLocked(bool locked)voidtrue でカーソルを隠して画面中央に固定する(FPS の視点操作用)
    IsCursorLocked()boolカーソルを固定しているか
    GetMouseWorldPosition()XMFLOAT22D 用: マウスのワールド座標(カメラ位置を考慮、Y+ は上方向)
    GetPadLeftStick(int padIndex)XMFLOAT2パッドの左スティック(-1〜1)
    GetPadRightStick(int padIndex)XMFLOAT2パッドの右スティック
    GetPadTrigger(int trigger, int padIndex)floatトリガー(TRIGGER_LEFT / TRIGGER_RIGHT)の押し具合(0〜1)

    SetHwnd(HWND hwnd)voidmain.cpp で1回だけ呼ぶ。マウス座標をこのウィンドウ基準にするため
    KEY_A#defineキーの名前のマクロ。KEY_A〜KEY_Z、KEY_0〜KEY_9、KEY_F1〜KEY_F12、KEY_SPACE、KEY_ENTER、KEY_ESCAPE、KEY_SHIFT、KEY_CTRL、KEY_ALT、KEY_TAB、KEY_BACK、KEY_UP / KEY_DOWN / KEY_LEFT / KEY_RIGHT

// 視点回転: 固定中だけ、マウスの移動量で回す(固定したフレームは使わない)

XMFLOAT2 delta = Input::GetMouseDelta();
yaw += delta.x * mouseSensitivity;
pitch -= delta.y * mouseSensitivity;

if (pitch > maxPitch) pitch = maxPitch;
    気を付ける点
    • 2D のオブジェクトとマウスを比べる時は GetMousePosition() ではなく GetMouseWorldPosition() を使います(カメラの位置を考慮済みで、Y+ が上)。GetMousePosition() はカメラを考えない「画面上の位置」です。
    • GetMousePosition() は Y+ が 下、GetMouseWorldPosition() は Y+ が 上 です。向きが逆なので注意。
    • カーソル固定中は、別のウィンドウを選んだり最小化したりすると自動で解除されます。固定したフレームの GetMouseDelta() は 0 です。
    • ポーズ中に操作を止めたい時は Time::IsPaused() で調べます(入力は時間の倍率の影響を受けません)。

    Engine/Core/MathUtil.h Engine/Core/MathUtil.cpp

    方向・距離・角度・乱数の計算をまとめた物です(Unity の Mathf と Vector3 の計算を合わせたもの)。角度はすべて 度 です。XMFLOAT2 / XMFLOAT3 の + - * も使えるようになります。

    名前引数・戻り値何をするか
    operator+ / operator- / operator*XMFLOAT2・XMFLOAT3ベクトルの足し算・引き算・何倍か(namespace DirectX に定義)
    Length(v)floatベクトルの長さ(XMFLOAT2 / XMFLOAT3 版)
    Distance(a, b)float2点の距離(XMFLOAT2 / XMFLOAT3 版)
    DistanceSq(a, b)float距離の2乗。大小を比べるだけなら sqrt が無くて速い
    Normalize(v)XMFLOAT2 / XMFLOAT3長さ1にする(長さがほぼ0なら 0 ベクトル)
    DirectionTo(from, to)XMFLOAT2 / XMFLOAT3from から to への向き(長さ1)
    Dot(a, b)float内積(XMFLOAT3)
    Cross(a, b)XMFLOAT3外積(2つに垂直な向き)。Cross({0,1,0}, 正面) が右

    Engine/Core/Time.h Engine/Core/Time.cpp

    1フレームの時間・起動してからの時間・時間の倍率(スロー / ポーズ)です。Unity の Time と同じです。

    SetTimeScale(float scale)void時間の倍率(1=通常、0.3=スロー、0=ポーズ)。負の値は 0 にする
    GetTimeScale()float今の倍率(シーン切り替えの演出中は 0)
    IsPaused()boolポーズ中か(倍率が 0 の時 true。シーン切り替えの演出中も true)
    Init() / Update()void内部用: GameEngine が呼ぶ

    使い方の例 出典: Demo/Game/Components/Core/TimeDemoController.cpp:28-28,33-34

// (中略)

    気を付ける点
    • 1フレームの時間には上限(0.1秒)があり、ウィンドウのドラッグ中などでも大きな値になりません。
    • シーン切り替えの演出の間は倍率 0 になります。演出中に SetTimeScale を呼んでも、演出が終わってから効きます。
    • ポーズ中でも動かしたい物(メニューなど)は GetUnscaledDeltaTime() を使います。
    • ポーズ中も、各 Component の Update は止まりません(dt が 0 で呼ばれ続けます。PhysX の物理は止まります)。キー入力を止めたい Controller は、Update の先頭に if (Time::IsPaused()) return; と書きます(README §10)。
    • Engine フォルダをインクルードパスに追加しないこと(標準の <time.h> と名前がぶつかります)。

    Engine/Core/Resources.h Engine/Core/Resources.cpp

    画像・音・モデルを「何度も読み込まない」ための仕組みです。同じパスのものは1回だけ読み、何人が使っているか(参照カウント)を数えます。SpriteRenderer や Audio が中で自動的に使うので、普段は意識しなくて構いません。

    名前で識別する通知の仕組みです(イベントバス / Pub-Sub)。「何が起きたか」を知らせる側と、それを聞いて動く側が、お互いを直接知らなくて済みます。アプリ全体で1つ(EventBus::Get())。

    名前引数・戻り値何をするか
    Get()static EventBus&唯一の EventBus を返す
    Subscribe(const std::string& eventName, Callback callback)void引数なしイベントを「聞く」登録。Callback は std::function<void()>
