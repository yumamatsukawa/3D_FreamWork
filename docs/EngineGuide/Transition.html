    Transition(シーン切り替えの演出)

    Engine/Transition/ は、シーンを切り替える時の演出です。「画面を覆う → シーンを切り替える → 開く」の順に進みます。ゲーム側は SceneManager::Get().ChangeScene<GameScene>(FadeTransition()); のように、演出を作って渡すだけです。 演出は Component ではありません(SceneTransition を継承したただのクラス)。種類は 2 つ: 色で暗転する FadeTransition と、スプライトシートの絵を再生する SpriteTransition。
    このページのファイル
    • SceneTransition.h / SceneTransition.cpp
    • FadeTransition.h / FadeTransition.cpp
    • SpriteTransition.h / SpriteTransition.cpp

    演出の間の約束: 覆っている間・開いている間は、ゲームの時間が止まります(Time の倍率 0。演出自体は止まらない時間で進む)。演出は文字や ScreenEffect よりさらに上に描かれます。切り替えを頼んでから終わるまでの間の ChangeScene は無視されます。

    Demo で見る: Demo プロジェクトの Render カテゴリの「Transition」(演出を見比べる)。

    Engine/Transition/SceneTransition.h Engine/Transition/SceneTransition.cpp

    シーン切り替えの演出の親クラスです。どの種類も「覆う → 切り替える → 開く」の順に進みます。覆い方・開き方は子クラスが override します。ゲーム側はこのクラスの関数を呼びません(SceneManager が呼びます)。

    子クラスが override する(新しい演出を作る人向け)

    名前引数・戻り値何をするか
    GetCoverDuration()float (純粋仮想)覆うのにかかる時間(秒)
    GetOpenDuration()float (純粋仮想)開くのにかかる時間(秒)
    OnBegin()void (virtual)覆い始める時に 1 回呼ばれる(画像の読み込みなど)
    DrawCover(ID2D1RenderTarget* target, float progress)void (純粋仮想)覆っている途中を描く。progress: 0=まだ何も覆っていない → 1=全体を覆った
    DrawOpen(ID2D1RenderTarget* target, float progress)void (純粋仮想)開いている途中を描く。progress: 0=全体を覆っている → 1=全部見えている

    内部用(SceneManager だけが呼ぶ。ゲーム側からは呼ばない)

    名前引数・戻り値何をするか
    Begin()void覆い始める(ChangeScene が呼ばれた時)
    Update(float unscaledDt)void毎フレーム 1 回、時間を進める
    BeginOpen()voidシーンを切り替えた後、開き始める
    Draw()void今の様子を画面の一番上に描く
    IsCovered()bool覆い終わって、シーンの切り替え待ちか
    IsFinished()bool開き終わったか
    使い方の例 出典: Sample2D/Game/Objects/StartButton.cpp:10-14
    GameObject* button = CreateButton(scene, L"START", { 0.f, -150.f }, [] {
    // 黒で0.5秒かけて暗転 → GameSceneへ切り替え → 0.5秒かけて明転
    // (切り替え中にもう一度押されても、SceneManagerが無視するので二重に切り替わらない)
    SceneManager::Get().ChangeScene<GameScene>(FadeTransition());
});
    気を付ける点
    • 継承の関係は SceneTransition ← FadeTransition / SpriteTransition です(設計図の継承図)。
    • 演出の時間は Time::GetUnscaledDeltaTime() で進みます(ゲームの時間は止まっています)。
    • シーンの読み込みで長くなったフレームの分は、演出の時間として進めません(skipNextUpdate)。

    Engine/Transition/FadeTransition.h Engine/Transition/FadeTransition.cpp

    暗転 → シーンを切り替える → 明転、の演出です(画面全体を 1 色で塗ります)。

    名前引数・戻り値何をするか
    FadeTransition(XMFLOAT4 color, float duration)コンストラクタ色(既定は黒 {0,0,0,1})と、覆う時間・開く時間(どちらも同じ秒数。既定 0.5)
    FadeTransition(const FadeTransition& other)コピーコンストラクタ色と時間だけを写す(ブラシは写さない)
    使い方の例 出典: Sample2D/Game/Objects/StartButton.cpp:13-13
    SceneManager::Get().ChangeScene<GameScene>(FadeTransition());
    気を付ける点
    • 色は color の x, y, z だけを使います(w は使いません。切り替える時は必ず画面全体を塗りつぶす)。
    • duration が 0 以下なら一瞬で切り替わります。
    • 白い暗転にする例: FadeTransition({ 1.f, 1.f, 1.f, 1.f }, 1.f)。

    Engine/Transition/SpriteTransition.h Engine/Transition/SpriteTransition.cpp

    スプライトシート(1 枚の画像に並べたコマ)を画面全体に引き伸ばして再生する演出です。普段は、覆う時はコマ 0 → 最後のコマ、開く時は最後のコマ → コマ 0 へ逆に再生します。

    名前引数・戻り値何をするか
    SpriteTransition(const std::wstring& path, int columns, int rows, float frameDuration)コンストラクタシートの画像・列数と行数・1 コマの時間(秒)
    SetOpenSheet(const std::wstring& path, int columns, int rows, float frameDuration)SpriteTransition&開く時だけ別の画像を使う(これも逆再生)。続けて書けるよう自分を返す
    SetSwitchFrame(int frame)SpriteTransition&シーンを切り替えるコマを決める。コマ 0〜frame で覆い、frame+1〜最後で開く(順再生だけ)
    UnloadAll()static void内部用: 読み込んだ画像をすべて解放する(GameEngine が呼ぶ)
    使い方の例 出典: Sample2D/Game/Components/GameManager.cpp:43-45
    if (gameOver && Input::GetKeyDown(KEY_SPACE)) {
    SceneManager::Get().ChangeScene<TitleScene>(SpriteTransition(L"Assets/transition_circle.png", 8, 2, 0.04f));
}
    使い方の例 出典: Sample3D/Game/Components/GameManager.cpp:47-47
    SceneManager::Get().ChangeScene<TitleScene>(SpriteTransition(L"Assets/transition_wipe.png", 8, 2, 0.04f).SetSwitchFrame(7));
    気を付ける点
    • 画像の作り方: コマは 左上から右へ、行の終わりまで行ったら次の行へ 並べます(SpriteRenderer のコマ番号と同じ)。最後のコマで画面全体が覆われるように描き、コマ 0 は全部透明にすると自然につながります。
    • 各コマは画面全体に引き伸ばされるので、1 コマの縦横比は画面と同じ(16:9)にするとゆがみません。
    • SetSwitchFrame を使う時は、そのコマで画面全体が覆われるように描き、最後のコマは全部透明 にします。frame は 0〜(コマ数 − 2) に収められます(範囲外は出力ウィンドウに知らせます)。
    • SetSwitchFrame と SetOpenSheet を一緒に使うと、SetSwitchFrame が優先されます。
    • 画像は Direct2D で読み込み、同じファイルは使い回します(終了時に解放)。読み込めなかった時は何も描かず、時間どおりに切り替えます。
