=page Network
=title Network(LAN 通信。ホストが計算して、結果を配る)
=lead
`Engine/Network/` は、同じ LAN につないだ **2〜4 台の PC** で 1 つのゲームを一緒に遊ぶための仕組みです。方式は**ホスト式**: 1 台が「ホスト」になって**ルールと物理(PhysX)の計算をホストだけ**で行い、「クライアント」は**入力**を送って、ホストから届いた**結果(位置・向き)を表示**します。PhysX は別の PC で同じ結果になる保証が無いので、みんなで同じ計算をするのではなく、「結果を配る」方式にしています。通信ライブラリは **ENet**(`ThirdParty/enet/`。MIT ライセンス)で、ゲームのコードは ENet を直接さわりません。
=p
**ゲームが触るのは `Network`(窓口。名前空間)と、2 つの Component(`NetworkIdentityComponent` / `NetworkTransformComponent`)だけ**です。`StartHost` / `Join` / `StartSearch` を呼ばない限り何もしないので、Sample2D / Sample3D は変わりません(オフラインでも `IsHost()` は `true`、`GetInput(0)` は自分の入力で、1 人用としてそのまま動きます)。
=p
**層は 4 つ**: 通信(`NetworkTransport` + ENet)→ 部屋(`NetworkSession` / `LanDiscovery`)→ 同期(`NetworkObjects` / Identity / Transform)→ ゲーム側。`GameEngine::Run` の中の順番は、`Input::Update` → **`Network::Update`**(受信)→ `Physics::Update` → シーンの `Update` → `Audio::Update` → **`Network::EndFrame`**(送信)です(設計図のページの「1 フレームの流れ」の図にも出ています)。
=p
**Demo で見る**: Demo プロジェクトの **Network カテゴリ**に、NetworkBasic(つなぐ・文字を送る)/ NetworkDiscovery(LAN のホストを探す)/ NetworkTransform(位置の同期。2D/3D)/ NetworkInput(入力の同期。2D/3D)/ NetworkEvent(スイッチと扉)/ NetworkSpawn(弾の出し入れ。2D/3D)の 6 つがあります。1 台で `Demo.exe` を 2 つ起動して試せます(README の §39)。

=notes
- **ルールを書く Component は、`Update` の最初に `if (!identity->HasAuthority()) return;`** と書きます。クライアントでは動かさず、ホストが計算した結果を表示するだけにするためです。
- **クライアントのコピーを Dynamic にしてはいけません**(クライアントの PhysX が勝手に動かし、ホストの位置とずれる)。工場関数で `Network::IsHost()` を見て、ホストは Dynamic、クライアントは Kinematic にします。
- 「Host / Join を同じシーンの中で押す」デモでは、役割が変わった時に同期する物を作り直す必要があります(Demo の `NetworkWorldController`)。ロビーのシーンで先につないでからゲームのシーンへ移る作りなら要りません。
- `this` を使うラムダを `Subscribe` / `RegisterPrefab` したら、**Scene の `Uninit` で `Network::ClearHandlers()`** を呼びます(`EventBus::Clear()` と同じ決まり)。
- **`SceneManager` は切り替え中の `ChangeScene` を無視する**ので、クライアントは切り替えが終わらなければ、2 秒ごとに最大 3 回やり直します。
- タイムアウトは 10〜20 秒です(ウィンドウをドラッグしている間やデバッガで止めた間は、ゲームが止まって応答できないため)。
- **同じ LAN の信頼できる相手が前提**です(暗号化・認証・ずる対策は無い)。インターネット越し(ルーター越し)は対象外です。クライアント予測と Owner 権限は、まだ作っていません。

=file Engine/Network/NetworkConfig.h
=role
ネットワークの**定数を 1 か所に集めた**ファイルです。最大人数(`maxPlayers`)・通信の版(`protocolVersion`)・ポート(`defaultPort` / `discoveryPort`)・送る回数(`defaultSnapshotRate` / `inputRate`)・タイムアウト・上限の数などがあります。

=file Engine/Network/NetworkTransport.h, NetworkTransport.cpp
=class NetworkTransport
=role
**ENet を包んだクラス**です。接続・送信・受信だけを担当します。**ENet を知っているのは、このファイルと `LanDiscovery.cpp` だけ**で、公開ヘッダーに `enet/enet.h` は出ません(`enet.h` は `winsock2.h` を読み込み、`windows.h` と衝突するため、ENet を読む `.cpp` は `#include "enet/enet.h"` を最初の行に書きます)。接続相手は `peerId`(整数)で呼びます。`Network` の外でも `new` できるので、ウィンドウ無しのテストで使えます。
=table
StartServer(int port, int maxPeers) | bool | 待ち受けを始める(失敗なら `false`)
StartClient() | bool | 接続する側の準備
Connect(const std::string& address, int port) | int | 接続を始める。相手の番号を返す(始められなければ -1)
Stop() | void | 全員に切断を知らせて(最大 0.2 秒待って)閉じる
Poll(Event& out) | bool | 溜まっている出来事(接続・切断・受信)を 1 つ取り出す。`false` になるまで呼ぶ
Send(int peerId, int channel, const void* data, size_t size, bool reliable) | bool | 送る。`reliable` が `true` なら必ず届く(届くまで送り直す)
Flush() | void | 溜めた送信をすぐ流す
DisconnectPeer(int peerId) | void | 溜めた送信を流してから切る
SetTimeouts(int minMs, int maxMs) | void | 応答が無い時に切るまでの時間
GetPeerRoundTrip(int peerId) | float | ENet が測った往復の時間(秒)
UpdateStats(float dt) | void | 1 秒ごとの送受信量を数え直す
=notes
- チャンネルは 3 つ: 0 = 信頼する通信(参加・出来事・スポーン)、1 = 入力・ping(信頼しない)、2 = 位置のスナップショット(信頼しない)。**チャンネルが違えば、お互いを待ちません**(信頼する通信の再送で、位置が遅れない)。
- 信頼しない通信は、ENet が「古い物が新しい物の後に届いたら捨てる」順序付きで送ります。

=file Engine/Network/NetworkSession.h, NetworkSession.cpp
=class NetworkSession
=role
「今つながっているみんな」のまとまり(**セッション**)です。参加者の名簿・プレイヤー番号の割り当て・参加の受付(Join / Accept / Reject)・切断の検知・ping を担当します。入力・出来事・同期など、ゲームの中身のパケットは `onPacket` で上の層(`Network`)に渡します。
=table
StartHost(const std::string& playerName, int port) | bool | 部屋を作る(最大人数より少し多く接続を受け、満員の人には断りの返事を送れるようにする)
Join(const std::string& address, int port, const std::string& playerName) | bool | 参加を申し込む。つながったら `Join` パケットを送る
Disconnect() | void | 抜ける / 部屋を閉じる
Update(float dt) | void | 受信と、タイムアウト・ping の処理(毎フレーム)
SendTo(int playerIndex, const NetworkWriter& packet, int channel, bool reliable) | bool | そのプレイヤーへ送る
SendToAll(const NetworkWriter& packet, int channel, bool reliable, int exceptPlayer) | void | ホストだけ: 接続中のクライアント全員へ
SendToHost(const NetworkWriter& packet, int channel, bool reliable) | bool | クライアントだけ: ホストへ
GetPlayerCount() | int | 今の人数
GetPing() | float | ホストとの往復の時間
=notes
- **断る理由**: 満員(5 人目)/ 通信の版が違う / ゲーム ID が違う / 壊れた Join。断られたクライアントは `GetLastError()` に理由が入り、`Offline` に戻ります。
- **番号の付け方**: 一番若い空き番号(1〜3)を渡します。抜けた人の番号は、次に参加した人が使います。
- 送り主のプレイヤー番号は、**パケットの中身ではなく接続(peer)から決めます**(偽装されない)。参加していない相手が送れるのは `Join` だけです。
- 接続してから `Join` が来ない相手は、5 秒で切ります。

=class LanDiscovery
=role
**LAN でホストを探す**仕組みです。ゲーム本体とは別の UDP ポート(`discoveryPort`)を使い、探す側が LAN 全体へ呼びかけ(ブロードキャスト)、ホストが呼びかけた相手だけに返事(ゲーム ID・ポート・ホスト名・人数)を返します。ゲーム ID が違う相手は無視します。
=table
StartResponder(const std::string& name, int port, int portOfDiscovery) | bool | ホスト側を始める(探索用ポートを使えなければ `false`。使えなくても IP 直接入力では参加できる)
StopResponder() | void | ホスト側をやめる
StartSearch(int portOfDiscovery) | bool | 探す側を始める(1 秒おきに呼びかける)
StopSearch() | void | 探す側をやめる
Update(float dt) | void | 呼びかけ・返事の処理。数秒返事が無いホストは一覧から消す

GetLocalAddresses() | static std::vector<std::string> | このPCのIPv4アドレスの一覧
=notes
- 呼びかけは、全体向け(`255.255.255.255`)・それぞれのネットワークの中向け(複数のアダプタがあっても届くように)・このPC自身(同じPCの別プロセス用)に送ります。
- **学校・公共の Wi-Fi は、ブロードキャストや端末どうしの通信を禁止している**ことがあります。その時は探索が動かないので、**IP アドレスの手入力(`Join`)を必ず残します**。
- 同じ探索用ポートを待ち受けられるのは 1 つのプロセスだけです。同じ PC の 2 つ目の `Demo.exe` は、探す側 / 参加する側として使います。

同期する物の**登録簿**(`NetworkId → GameObject`)と、**プレハブ**(番号 → 工場関数)・スポーンした物の記録です。各 Component の `Init` / `Uninit` / `OnActiveChanged` が自動で登録・解除するので、**シーンが変わっても前のシーンのポインタが残りません**。ゲーム側が直接呼ぶことはほとんどありません(`NetworkSpawnInfo` は、工場関数が受け取る情報)。

=class NetworkIdentityComponent
=role
**同期する物に付ける印**です(NetworkId・所有者・Authority)。ホストの物にも、クライアントのコピーにも同じ Component を付けます。違いは `HasAuthority()` が決めます。
=table

GetNetworkId() | int | 番号(0 = まだ無い)

SetOwnerPlayerIndex(int playerIndex) | void | 所有者を決める
IsOwner() | bool | 所有者が自分か

SetSpawnInfo(int id, int prefab, int owner) | void | 内部用: Network がスポーンの時に呼ぶ
=notes
- 非アクティブ(`ObjectPool` に返した)になると登録簿から外れます。**スポーンした物は番号を手放す**ので、次の `Spawn` で新しい番号が付きます(古い番号で登録し直されて、別の物とぶつからない)。
- 同じ番号を 2 つの物に付けると、出力ウィンドウに知らせて、後の物が勝ちます。

LerpAngle(float from, float to, float t) | static float | 角度(度)の補間。360 度をまたぐ時は近い向きに回る
=notes
- 設定(`NetworkTransformSettings`): `syncPosition` / `syncRotation` / `syncScale`(変わった時だけ送る)/ `is2D`(`position.xy` と `rotate.z` だけ送る)/ `teleportDistance`(これ以上離れたら補間せずに飛ぶ。既定 500)。
- **同期するのは親を持たない(ルートの)オブジェクトだけ**です。
- 表示の時刻が最新より後(通信が遅れた)なら、最新の位置で止めます(予測では動かさない)。
- 受け取った位置は ±1,000,000 に収め、NaN・知らない印・短すぎる写真は捨てます。
