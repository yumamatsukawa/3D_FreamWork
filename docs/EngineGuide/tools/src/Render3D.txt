=page Render3D
=title Render3D(3D描画・ライト・影・地形・水)
=lead
`Engine/Render3D/` は、3D の見た目を作る仕組みです。立体の形(Mesh)、見た目の設定(Material)、ライトと影、FBX モデル、地形、水面、遠くの物を省く LOD が入っています。
3D の物は `MeshRenderer`(自分で作った形)か `ModelRenderer`(FBX モデル)を GameObject に付けて描きます。
=p
**Demo で見る**: Demo プロジェクトの **Render3D カテゴリ**に、Shapes / Light / Shadow / Outline / Terrain / Water / Model / SkinAnim / LOD / Visibility の10個のデモがあります(Terrain の当たり判定は Physics カテゴリの TerrainCollider)。

=file Engine/Render3D/MeshRenderer.h
=class MeshRenderer
=role
GameObject に「3D メッシュを描く見た目」を持たせる Component です(`SpriteRenderer` の 3D 版)。見た目は `Material` にまとめて持ちます。影を落とす物としても登録されます(`Shadow::Caster`)。

MeshRenderer(const std::vector<MeshVertex>& vertices) | コンストラクタ | 形(頂点データ)を渡して作る。例: `AddComponent<MeshRenderer>(Mesh::CreateCube())`
SetMaterial(const Material& value) | void | マテリアルをまとめて設定する
GetMaterial() | Material& | 手直し用。例: `GetMaterial().specularStrength = 0.8f;`
SetTexture(const std::wstring& filepath) | void | 画像を貼る(`material.texture` を書き換える)
SetColor(float r, float g, float b, float a) | void | 色(`material.color`)
GetColor() | XMFLOAT4 | 今の色
SetRimLight(XMFLOAT3 color, float strength, float power) | void | 縁の光(リム発光)。`strength=0` で消す。`power` は既定 3
SetOutline(XMFLOAT4 color, float widthPixels, bool seeThrough) | void | 枠線。画面上で `widthPixels` の太さ。0 で消す。`seeThrough=true` で壁越しにも見える
SetUnlit(bool value) | void | `true` で光の影響を受けない(スカイボックスなど)
SetDepthWrite(bool value) | void | `false` で深度を書かない(自分より後ろの物を隠さない。スカイボックス用)
SetFrustumCulling(bool enabled) | void | `true` で、画面の外にある時は描かない
IsFrustumCulling() | bool | 画面の外を省く設定か
SetLod(const LodSettings& settings) | void | 距離で省く設定をまとめて渡す
GetLod() | LodSettings& | 手直し用(`drawDistance` など)
Init() / Draw() / Uninit() / DrawShadow(...) | void (override) | 内部の処理(影の登録・描画・影のパス・後片付け)
=code Demo/Game/Objects/Core/TransformDemo.cpp:18-21
=code Sample3D/Game/Objects/Player.cpp:16-20
=notes
- 影を落とすには `GetMaterial().castShadow = true`、影を受けるには `receiveShadow = true`(どちらも既定は `false`)。さらに `Shadow::GetSettings().enabled = true` が必要です。
- 枠線(`SetOutline`)は、`material.depthWrite = false` の物(スカイボックス・半透明の板)には描かれません。壁越しの枠線を使う時は、その物の `SetDrawPriority` を大きくします(あとで描かれる壁に上書きされないように)。
- `SetFrustumCulling(true)` は、物が画面の端で消えて見えたら `false` に戻します(`Visibility::GetCulledCount` で確認)。`SetDepthWrite(false)` の物(画面全体を覆う)は判定しません。
- 3D メッシュの描画は 3D 用カメラ(`Image::GetCamera3D()`)を使います。
- 2D の `SpriteRenderer` には、ライト・影・枠線は効きません。

=notes
- `Mesh::Init` が `false` の時は `Uninit` を呼びません。
- 立方体・球は「大きさ 1 の形を `scale` で伸ばす」物ですが、**カプセルは伸ばすと半球が潰れる**ので実際の大きさで作ります。

=file Engine/Render3D/Material.h
=class Material, MaterialConstantBuffer
=role
3D メッシュの見た目の設定をまとめた構造体です(色・画像・光沢・自発光・影・縁の光・枠線)。`MeshRenderer` / `ModelRenderer` が 1 体ごとに持ちます。Unity の Material に近い考え方です。既定値のままなら、マテリアルが無かった頃と見た目は同じです。
=table 基本
color | XMFLOAT4 | 色(a が透明度。1=不透明)。1 より大きい値も使える(暗い画像を明るくする)
texture | std::wstring | 画像のパス(空なら白)
lit | bool | `false` で光の影響を受けない(スカイボックス)
depthWrite | bool | `false` で自分より後ろの物を隠さない(半透明・スカイボックス)
=table 光沢・自発光
specularColor | XMFLOAT3 | 光沢の色
specularStrength | float | 光沢の強さ。0=ハイライト無し(既定)
shininess | float | 光沢の鋭さ(既定 32)
emissiveColor | XMFLOAT3 | 自分で光る色
emissiveStrength | float | 自発光の強さ。0=光らない(既定)
=table 影・縁の光・枠線
castShadow | bool | 影を落とすか(既定 `false`)
receiveShadow | bool | 影を受けるか(既定 `false`)
rimColor / rimStrength / rimPower | XMFLOAT3 / float / float | 縁の光の色・強さ(0=光らない)・集まり方(大きいほど細い線)
outlineColor | XMFLOAT4 | 枠線の色
outlineWidth | float | 枠線の太さ(画面のピクセル)。0=枠線なし(既定)
outlineSeeThrough | bool | `true` で壁越しにも枠線を描く
MakeMaterialConstantBuffer(const Material& material) | MaterialConstantBuffer | 内部用: シェーダーへ送る形に変換する
=code Sample3D/Game/Components/GroundController.cpp:24-28
=notes
- 半透明にする時は `color.w` を下げ、`depthWrite = false` にします(後ろの物が隠れないように)。描く順番は `SetDrawPriority` で調整します。
- 影は `Shadow::GetSettings().enabled = true` の時だけ意味があります。
- `MaterialConstantBuffer` は、シェーダー(`Shader3DCommon.hlsli` の `MaterialBuffer`)と同じ並びです。Engine を触る人以外は触りません。

=code Sample3D/Game/Components/ShadowManager.cpp:4-14
=notes
- 影を落とせるのは `MeshRenderer` / `ModelRenderer`(スキンメッシュを含む)/ `TerrainRenderer`。**`SpriteRenderer`(画像)は影を落とせません**。
- 影が出る光は、平行光源(`Image::GetLight()`)と、`SetCastShadow(true)` にしたスポットライト 1 つだけです。環境光と点光源は影で暗くなりません。

=class Lod(名前空間), LodSettings
=role
LOD(Level Of Detail)の段階 1 です。カメラから遠い物を「描かない・影を落とさない・枠線を描かない」で軽くします。距離は「カメラから物の球の表面まで」です。
=table LodSettings(MeshRenderer などが 1 つずつ持つ)
drawDistance | float | これより遠い物は描かない(0 = いつも描く)
shadowDistance | float | これより遠い物は影を落とさない(0 = いつも落とす)
outlineDistance | float | これより遠い物は枠線を描かない(0 = いつも描く)
=table Lod 名前空間
SetEnabled(bool enabled) | void | `false` で、すべての物の LOD 設定を無視する(LOD を使わない状態と比べる確認用。既定 `true`)
IsEnabled() | bool | LOD が有効か
SetGlobalScale(float scale) | void | すべての距離を何倍にするか(0.5 で半分。0 以下は 1 に戻す)
GetGlobalScale() | float | 今の倍率
GetCameraDistance(XMFLOAT3 position) | float | カメラから position までの距離
IsBeyond(XMFLOAT3 center, float radius, float limit) | bool | 球の表面までの距離が limit を超えているか(`limit` が 0 以下なら `false`)
IsBeyond(const XMMATRIX& world, float localRadius, float limit) | bool | ワールド行列を持つ物版
=code Sample3D/Game/Objects/WallField.cpp:12-16
=code Sample3D/Game/Objects/WallField.cpp:27-29
=notes
- 省くのは **見た目だけ** で、物理(当たり判定)は止まりません。
- 影は「カメラからの距離」で判断します。光の向きによっては遠い物の影が近くの地面に落ちるので、`shadowDistance` を短くしすぎないこと。
- 大きな物は、中心が遠くても手前の端が近ければ省かれません。ちょうど設定の距離なら省きません(超えたら省く)。
- `MeshRenderer` / `ModelRenderer` / `TerrainRenderer` が使います(地形は `drawDistance` / `shadowDistance` のみ)。

=notes
- **仕組み**: 文字を Direct2D(`Text` と同じフォント・並べ方)で **テクスチャに描き**、四角い板(`Mesh`)に貼って、`MeshRenderer` と同じ経路(Shader3D・深度バッファ)で描きます。画面の文字(`TextRenderer`)は Direct2D で最後に画面へ重ねるので、3D の物の後ろには隠れません。壁に貼る・物に隠れる文字は `WorldTextRenderer` を使います。
- **向き**: 板の正面は `-Z` 側(`SpriteRenderer` のビルボードと同じ)。位置・向き・大きさは、オーナーの `transform`(親子込み)。`align` が `Left` なら板の左端、`Right` なら右端がオーナーの位置、`Center` は板の中心です。
- **ビルボード**: `SetBillboard(true)` でオーナーの回転を使わず、いつもカメラ(CameraShake 込み)の方を向きます。`transform.rotate.z` だけは板の中の回転になります。
- **大きさ**: 板の大きさ = テクスチャのピクセル数 ÷ `SetPixelsPerUnit`。例: 64 ピクセルの文字は、既定で高さ 32 ワールド。`transform.scale` でさらに拡大縮小できます。テクスチャは 2048 ピクセルまでで、超える文字は **見た目の大きさを変えずに細かさを下げ**、出力ウィンドウに知らせます。
- **半透明と描く順番**: 文字のふちのなめらかさ(アンチエイリアス)を保つため、半透明で重ね、深度には書きません(物の後ろには隠れますが、後ろの物は隠しません)。そのため **壁などの不透明な物より後に描く** 必要があり、`Init` でオーナーの `drawPriority` が 0 なら 10 にします(変えたい時は `GetOwner()->SetDrawPriority()`)。背景が不透明(`SetBackground` の a=1、文字の濃さ 1)なら、深度にも書くふつうの板になります。
- **テクスチャの共有**: 文字・フォント・ピクセルの大きさ・太字・色・縁取り・寄せ方・背景・テクスチャの大きさ(絵を決める設定)が **すべて同じなら、板が何枚あってもテクスチャは 1 枚** です。板の大きさ・向き・ビルボード・光・両面は絵に関係しないので、共有を妨げません。同じ看板を 100 枚並べても 1 枚分のメモリです。
- **文字や見た目を変えた時**: 共有テクスチャは作ったあと **書き換えません**。変えると、今のテクスチャを手放し(借りている数を 1 減らす)、新しい設定のテクスチャを借りに行きます(あれば共有、無ければ新しく描く)。ほかの看板の文字は変わりません。借りている数が 0 になったテクスチャは **すぐ解放** されます(シーンを出た時も、`Engine` の終了時も)。
- **制限**: 毎フレーム変わる文字(カウントなど)は共有されず、変わるたびに新しいテクスチャを描く(Direct2D で描いて GPU に送る)ので重くなります。**数字が変わった時だけ** `SetText` を呼びます(同じ文字なら何もしません)。共有のテクスチャが 256 枚を超えると、出力ウィンドウに 1 回知らせます(止めはしません)。
- 日本語を使う時は `Text::LoadFont` で読んだフォント名を `style.fontName` に入れます(`TextRenderer` と同じ)。影は落とさず・受けません。
