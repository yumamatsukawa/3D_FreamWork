    Render3D(3D描画・ライト・影・地形・水)

    Engine/Render3D/ は、3D の見た目を作る仕組みです。立体の形(Mesh)、見た目の設定(Material)、ライトと影、FBX モデル、地形、水面、遠くの物を省く LOD が入っています。 3D の物は MeshRenderer(自分で作った形)か ModelRenderer(FBX モデル)を GameObject に付けて描きます。

    Engine/Render3D/MeshRenderer.h

    GameObject に「3D メッシュを描く見た目」を持たせる Component です(SpriteRenderer の 3D 版)。見た目は Material にまとめて持ちます。影を落とす物としても登録されます(Shadow::Caster)。

    名前引数・戻り値何をするか
    MeshRenderer(const std::vector<MeshVertex>& vertices)コンストラクタ形(頂点データ)を渡して作る。例: AddComponent<MeshRenderer>(Mesh::CreateCube())
    SetMaterial(const Material& value)voidマテリアルをまとめて設定する
    GetMaterial()Material&手直し用。例: GetMaterial().specularStrength = 0.8f;
    SetTexture(const std::wstring& filepath)void画像を貼る(material.texture を書き換える)
    SetColor(float r, float g, float b, float a)void色(material.color)
    GetColor()XMFLOAT4今の色
    SetRimLight(XMFLOAT3 color, float strength, float power)void縁の光(リム発光)。strength=0 で消す。power は既定 3
    SetOutline(XMFLOAT4 color, float widthPixels, bool seeThrough)void枠線。画面上で widthPixels の太さ。0 で消す。seeThrough=true で壁越しにも見える
    SetUnlit(bool value)voidtrue で光の影響を受けない(スカイボックスなど)
    SetDepthWrite(bool value)voidfalse で深度を書かない(自分より後ろの物を隠さない。スカイボックス用)
    SetFrustumCulling(bool enabled)voidtrue で、画面の外にある時は描かない
    IsFrustumCulling()bool画面の外を省く設定か
    SetLod(const LodSettings& settings)void距離で省く設定をまとめて渡す
    GetLod()LodSettings&手直し用(drawDistance など)
    Init() / Draw() / Uninit() / DrawShadow(...)void (override)内部の処理(影の登録・描画・影のパス・後片付け)
    使い方の例 出典: Demo/Game/Objects/Core/TransformDemo.cpp:18-21
    if (is3D) {
    parent->transform.position = { 0.f, 0.f, 300.f };
    parent->AddComponent<MeshRenderer>(Mesh::CreateCube())->SetColor(0.4f, 0.6f, 0.9f, 1.0f);
}
    使い方の例 出典: Sample3D/Game/Objects/Player.cpp:16-20
    // 見た目(3Dメッシュの立方体)
auto* meshRenderer = player->AddComponent<MeshRenderer>(Mesh::CreateCube());
meshRenderer->GetMaterial().castShadow = true;     // 影を落とす(地面に影が出る)
meshRenderer->GetMaterial().receiveShadow = true;  // 壁などの影を受ける
meshRenderer->SetRimLight({ 0.3f, 0.7f, 1.0f }, 1.0f);   // 縁が青く光る(斜めに見える面が少し青くなる)
    気を付ける点
    • 影を落とすには GetMaterial().castShadow = true、影を受けるには receiveShadow = true(どちらも既定は false)。さらに Shadow::GetSettings().enabled = true が必要です。
    • 枠線(SetOutline)は、material.depthWrite = false の物(スカイボックス・半透明の板)には描かれません。壁越しの枠線を使う時は、その物の SetDrawPriority を大きくします(あとで描かれる壁に上書きされないように)。
    • SetFrustumCulling(true) は、物が画面の端で消えて見えたら false に戻します(Visibility::GetCulledCount で確認)。SetDepthWrite(false) の物(画面全体を覆う)は判定しません。
    • 3D メッシュの描画は 3D 用カメラ(Image::GetCamera3D())を使います。
    • 2D の SpriteRenderer には、ライト・影・枠線は効きません。

    Engine/Render3D/Mesh.h Engine/Render3D/Mesh.cpp

    3D の頂点データを持って描くクラスです。立方体・球・カプセルなどの形を作る Create○○ 関数もここにあります。普段は MeshRenderer 経由で使い、Mesh を直接触るのは Engine を触る人(や、GroundController のように自分で Draw する時)です。

    形を作る(static、戻り値は std::vector<MeshVertex>)

    名前引数・戻り値何をするか
    CreateCube()頂点データ単位立方体(-0.5〜0.5)。大きさは transform.scale
    CreateSphere(int rings, int segments)頂点データ半径 0.5 の球。分割数が多いほど滑らか(既定 16, 24)
    CreateCapsule(float radius, float height, int rings, int segments)頂点データカプセル(長い向きは Y)。実際の大きさで作る(scale は 1 のまま)
    LoadOBJ(const std::wstring& filepath)頂点データWavefront OBJ ファイルから作る。失敗したら空
    CreateCubeOutline() / CreateSquareOutline() / CreateCircleOutline(int) / CreateSphereOutline(int) / CreateCapsuleOutline(...)頂点データ(線)輪郭の線だけのデータ(コライダーのデバッグ表示用。LINELIST で Init する)
    CreateSmoothNormals(positions, normals, indices)std::vector<XMFLOAT3>内部用: 枠線のための、平均した法線

    描く・作る

    名前引数・戻り値何をするか
    Init(const std::vector<MeshVertex>& verts, D3D11_PRIMITIVE_TOPOLOGY topology)bool頂点バッファを作る(1回だけ)。失敗したら false
    InitIndexed(verts, indices, topology)boolインデックス付きで作る(地形のように頂点が多い形向き)
    Draw(const Transform& transform, const Camera& camera, const Material& material, const Light& light)voidマテリアル付きで描く。行列版・色だけの版もある
    DrawLines2D(transform, camera2D, color, light)void2D(XY 平面)の線を描く(デバッグ表示用)
    DrawOutline(world, camera, color, widthPixels, seeThrough)void枠線を描く(本物を Draw した直後に呼ぶ)
    DrawDepth(world, lightView, lightProj)void影のパス用: 深度だけを描く
    SetTexture(ID3D11ShaderResourceView* s)void貼る画像を渡す(Image::GetTextureView(texID) の結果)
    Uninit()void解放する

    型

    名前引数・戻り値何をするか
    MeshVertexstruct頂点: Position・Normal・Color・TexCoord
    CapsuleAxisenum classカプセルの長い向き: X / Y / Z(CapsuleRigidbodyComponent でも使う)
    使い方の例 出典: Sample3D/Game/Components/GroundController.cpp:30-43
    // 範囲内のタイルを並べて描く(カメラに映らないタイル=後ろや横、描画距離の外は描かない)
Transform tile;
tile.scale = { tileSize, tileThickness, tileSize };
for (int z = minZ; z <= maxZ; z++) {
    for (int x = minX; x <= maxX; x++) {
        float centerX = (x + 0.5f) * tileSize;
        float centerZ = (z + 0.5f) * tileSize;
        XMFLOAT3 center = { centerX, topY - tileThickness * 0.5f, centerZ };
        if (!Visibility::IsSphereInView3D(center, tileSize * 0.8f)) continue;   // 0.8 = 正方形の対角線の半分(約0.71)に余裕を足した値

        tile.position = center;
        mesh.Draw(tile, camera, material, Image::GetLight());
    }
}
    気を付ける点
    • Mesh::Init が false の時は Uninit を呼びません。
    • 立方体・球は「大きさ 1 の形を scale で伸ばす」物ですが、カプセルは伸ばすと半球が潰れるので実際の大きさで作ります。
    • Draw の Material::texture(パス)は、Mesh では使いません。画像は SetTexture で渡します(MeshRenderer / ModelRenderer が読んで渡します)。
    • DrawOutline は material.depthWrite = false の物には使いません(内側まで枠線の色になる)。
    • 頂点バッファは作る時に 1 回だけ作り、描くたびにコピーしません(変更不可)。

    Engine/Render3D/Material.h

    3D メッシュの見た目の設定をまとめた構造体です(色・画像・光沢・自発光・影・縁の光・枠線)。MeshRenderer / ModelRenderer が 1 体ごとに持ちます。Unity の Material に近い考え方です。既定値のままなら、マテリアルが無かった頃と見た目は同じです。

    基本

    名前引数・戻り値何をするか
    colorXMFLOAT4色(a が透明度。1=不透明)。1 より大きい値も使える(暗い画像を明るくする)
    texturestd::wstring画像のパス(空なら白)
    litboolfalse で光の影響を受けない(スカイボックス)
    depthWriteboolfalse で自分より後ろの物を隠さない(半透明・スカイボックス)

    光沢・自発光

    名前引数・戻り値何をするか
    specularColorXMFLOAT3光沢の色
    specularStrengthfloat光沢の強さ。0=ハイライト無し(既定)
    shininessfloat光沢の鋭さ(既定 32)
    emissiveColorXMFLOAT3自分で光る色
    emissiveStrengthfloat自発光の強さ。0=光らない(既定)

    影・縁の光・枠線

    名前引数・戻り値何をするか
    castShadowbool影を落とすか(既定 false)
    receiveShadowbool影を受けるか(既定 false)
    rimColor / rimStrength / rimPowerXMFLOAT3 / float / float縁の光の色・強さ(0=光らない)・集まり方(大きいほど細い線)
    outlineColorXMFLOAT4枠線の色
    outlineWidthfloat枠線の太さ(画面のピクセル)。0=枠線なし(既定)
    outlineSeeThroughbooltrue で壁越しにも枠線を描く
    MakeMaterialConstantBuffer(const Material& material)MaterialConstantBuffer内部用: シェーダーへ送る形に変換する
    使い方の例 出典: Sample3D/Game/Components/GroundController.cpp:24-28
    // 地面は影を受ける(Shadow が有効な時、Playerや壁の影が落ちる。無効なら今まで通りの見た目)
Material material;
material.receiveShadow = true;
// 画像(bg_tile.png)がとても暗い(平均RGB約23,28,68)ので、色を掛けて明るい青灰色にする(1より大きくてよい。暗いままだと影が見えない)
material.color = { 5.0f, 4.0f, 2.0f, 1.0f };
    気を付ける点
    • 半透明にする時は color.w を下げ、depthWrite = false にします(後ろの物が隠れないように)。描く順番は SetDrawPriority で調整します。
    • 影は Shadow::GetSettings().enabled = true の時だけ意味があります。
    • MaterialConstantBuffer は、シェーダー(Shader3DCommon.hlsli の MaterialBuffer)と同じ並びです。Engine を触る人以外は触りません。

    Engine/Render3D/Light.h

    平行光源(太陽のように、全体に同じ向きから当たる光)と環境光です。Image::GetLight() で 1 つだけ取り出して使います。

    名前引数・戻り値何をするか
    directionXMFLOAT3光が進んでいく向き(既定 0, -1, 0.5)。長さは 1 でなくてよい
    colorXMFLOAT3光の色・強さ(既定 1,1,1)
    ambientXMFLOAT3環境光(光が当たらない面の最低限の明るさ。既定 0.25)
    使い方の例 出典: Demo/Game/Components/Render3D/ShadowDemoController.cpp:43-43
    Image::GetLight().direction = { cosf(elevation) * sinf(yaw), -sinf(elevation), cosf(elevation) * cosf(yaw) };
    気を付ける点
    • 2D のスプライトには効きません(Shader.hlsl は光の計算をしません)。
    • 影が出る光は、この平行光源と、SetCastShadow(true) にしたスポットライト 1 つだけです。

    Engine/Render3D/LightComponent.h Engine/Render3D/LightComponent.cpp

    付けた物の位置から光る、点光源・スポットライトです。Unity の Light の Point / Spot にあたります。3D のメッシュだけに効きます。

    名前引数・戻り値何をするか
    LightComponent(LightType lightType)コンストラクタLightType::Point(ランタン)か LightType::Spot(懐中電灯)
    SetColor(float r, float g, float b)void光の色(既定 白)
    SetIntensity(float value)void強さ(既定 1)
    SetRange(float distance)void光が届く距離(既定 800。100 単位 = 1m)
    SetDirection(XMFLOAT3 newDirection)voidスポットの向き(長さ 0 に戻すとオーナーの正面)
    SetSpotAngle(float innerDegrees, float outerDegrees)voidスポットの内側(全開)と外側(消える)の角度(既定 20 / 35)
    SetCastShadow(bool value)void影を落とす光にする(スポットライトだけ)
    IsCastingShadow()bool影を落とす設定か
    GetLightType()LightType光の種類
    GetColor() / GetIntensity() / GetRange() / GetInnerAngle() / GetOuterAngle()値各設定を返す
    GetWorldPosition()XMFLOAT3光の位置(オーナーのワールド座標)
    GetWorldDirection()XMFLOAT3スポットの向き(長さ 1)
    Init() / Uninit()void (override)Lighting への登録・解除
    使い方の例 出典: Sample3D/Game/Objects/Lantern.cpp:19-22
    auto* light = lantern->AddComponent<LightComponent>(LightType::Point);
light->SetColor(1.0f, 0.7f, 0.35f);
light->SetIntensity(1.5f);
light->SetRange(800.0f);
    使い方の例 出典: Sample3D/Game/Objects/Guard.cpp:28-33
    auto* torch = guard->AddComponent<LightComponent>(LightType::Spot);
torch->SetColor(1.0f, 0.95f, 0.8f);
torch->SetIntensity(6.0f);
torch->SetRange(1500.0f);
torch->SetSpotAngle(15.0f, 30.0f);
torch->SetCastShadow(true);   // 懐中電灯の光も影を作る(壁やPlayerの後ろは光が届かない。影を落とすスポットは1つだけ)
    気を付ける点
    • 同時に使える光は 8 個(Lighting::maxLights)。超えたら 3D カメラに近い 8 個だけが光ります。超えた時は出力ウィンドウに警告が 1 回出ます。
    • SetActive(false) / SetEnabled(false) / Destroy の光は使われません(ObjectPool で休んでいる光も光りません)。
    • スポットライトの影は、同時に 1 つだけ(影を落とす光が複数ある時は、3D カメラに近い 1 つ)。外側の角度が 60 度を超える部分には影が出ません。点光源の影は作れません。
    • 2D のスプライトには効きません。

    Engine/Render3D/Lighting.h Engine/Render3D/Lighting.cpp

    点光源・スポットライト(LightComponent)の一覧を集めて、シェーダーに送る仕組みです。ゲーム側は LightComponent を付けるだけで、この名前空間は直接呼びません。

    名前引数・戻り値何をするか
    maxLightsconstexpr int同時に使える光の数(8)
    Register(LightComponent* light) / Unregister(LightComponent* light)void内部用: LightComponent の Init / Uninit が呼ぶ
    Update()void内部用: 毎フレーム、カメラに近い順に maxLights 個を選ぶ(GameEngine が呼ぶ)
    Bind()void内部用: Mesh / SkinMesh が描く時に光の定数バッファ(b4)をセットする
    Shutdown()void内部用: 終了時の片付け
    Build(lights, lightCount, cameraX, cameraY, cameraZ, overflowed, shadowLight)LightConstantBuffer光の一覧から、送る内容を作る(確認用に公開されている)
    GetActiveCount()int今フレームに使っている光の数(確認用)
    GetShadowSpotLight()const LightComponent*今フレームの、影を落とすスポットライト(無ければ nullptr)
    気を付ける点
    • 1 つも光が無い時の見た目は、点光源が無かった頃と同じです。
    • 光の数を HUD に出したい時は Lighting::GetActiveCount() が使えます。

    Engine/Render3D/Shadow.h Engine/Render3D/Shadow.cpp

    影(シャドウマップ)です。光から見た「深度」を専用のテクスチャに描き、本番の描画で「光から見て手前に別の物があるピクセル」を暗くします。既定は 無効 で、無効の間はコストが 0 です。

    使う側(ゲーム側)

    名前引数・戻り値何をするか
    GetSettings()Settings&影の設定を取り出す。enabled = true で影が出る
    SetSettings(const Settings& settings)void設定をまとめて入れる(Shadow::Settings() で既定に戻せる)
    Settings::enabledbool影を使うか(既定 false)
    Settings::resolutionint影のテクスチャの大きさ(1024 / 2048 / 4096。既定 2048)。大きいほどくっきりして重い
    Settings::distancefloatカメラの前方、この大きさの範囲に影を作る(既定 3000)。広いほどぼやける
    Settings::depthBias / normalBiasfloat縞模様(シャドウアクネ)を防ぐゆとり。大きすぎると影が浮く
    Settings::strengthfloat影の濃さ(0=なし、1=真っ暗。既定 0.6)
    Settings::pcfRadiusint影の縁のぼかし(0=なし、1=3x3、2=5x5)
    Settings::spotResolution / spotDepthBias / spotStrengthint / float / floatスポットライトの影の設定
    GetCasterCount() / GetDrawnCount() / IsSpotShadowActive()int / bool確認用の数

    内部用(Engine を触る人向け)

    名前引数・戻り値何をするか
    Casterclass影を落とす物(MeshRenderer / ModelRenderer / TerrainRenderer)が実装する。DrawShadow(const LightView&) を持つ
    Register(Component* component, Caster* caster) / Unregister(Caster* caster)void影を落とす物の登録・解除
    Render()void影のパス。深度テクスチャに描き、描画先を元に戻す(GameEngine が呼ぶ。無効の時は何もしない)
    Bind()void描く時に影の定数バッファ・テクスチャをセットする(Mesh / SkinMesh が呼ぶ)
    Shutdown()void終了時の片付け
    BuildSpotView(position, direction, outerAngleDegrees, range)LightViewスポットライトから見る行列を作る
    BuildSunView(camera, light, distance, resolution)LightView平行光源から見る行列を作る(カメラが動いても縁がちらつかないよう丸める)
    使い方の例 出典: Sample3D/Game/Components/ShadowManager.cpp:4-14
    void ShadowManager::Init() {
    // 影を有効にする(平行光源 Image::GetLight() の向きで影ができる。ほかの値は既定のまま)
    Shadow::Settings& settings = Shadow::GetSettings();
    settings.enabled = true;
    settings.distance = shadowDistance;
}

void ShadowManager::Uninit() {
    // 設定は全シーンで共通なので、このシーンが終わったら既定(影なし)に戻す
    Shadow::SetSettings(Shadow::Settings());
}
    気を付ける点
    • 影を落とせるのは MeshRenderer / ModelRenderer(スキンメッシュを含む)/ TerrainRenderer。SpriteRenderer(画像)は影を落とせません。
    • 影が出る光は、平行光源(Image::GetLight())と、SetCastShadow(true) にしたスポットライト 1 つだけです。環境光と点光源は影で暗くなりません。
    • 影の範囲の外では影が出ません(範囲は 3D カメラの前方 distance)。
    • 設定は全シーンで共通です。使い終わったら Shadow::SetSettings(Shadow::Settings()) で既定(影なし)に戻します(上の例の Uninit)。
    • 影のパスは Direct2D(文字)の描画の前に終えます(GameEngine の順番)。

    Engine/Render3D/Lod.h Engine/Render3D/Lod.cpp

    LOD(Level Of Detail)の段階 1 です。カメラから遠い物を「描かない・影を落とさない・枠線を描かない」で軽くします。距離は「カメラから物の球の表面まで」です。

    LodSettings(MeshRenderer などが 1 つずつ持つ)

    名前引数・戻り値何をするか
    drawDistancefloatこれより遠い物は描かない(0 = いつも描く)
    shadowDistancefloatこれより遠い物は影を落とさない(0 = いつも落とす)
    outlineDistancefloatこれより遠い物は枠線を描かない(0 = いつも描く)

    Lod 名前空間

    名前引数・戻り値何をするか
    SetEnabled(bool enabled)voidfalse で、すべての物の LOD 設定を無視する(LOD を使わない状態と比べる確認用。既定 true)
    IsEnabled()boolLOD が有効か
    SetGlobalScale(float scale)voidすべての距離を何倍にするか(0.5 で半分。0 以下は 1 に戻す)
    GetGlobalScale()float今の倍率
    GetCameraDistance(XMFLOAT3 position)floatカメラから position までの距離
    IsBeyond(XMFLOAT3 center, float radius, float limit)bool球の表面までの距離が limit を超えているか(limit が 0 以下なら false)
    IsBeyond(const XMMATRIX& world, float localRadius, float limit)boolワールド行列を持つ物版
    使い方の例 出典: Sample3D/Game/Objects/WallField.cpp:12-16
    // 距離で省く設定(カメラから柱の表面までの距離。遠いほど軽くする)
LodSettings lod;

    気を付ける点
    • 仕組み: 文字を Direct2D(Text と同じフォント・並べ方)で テクスチャに描き、四角い板(Mesh)に貼って、MeshRenderer と同じ経路(Shader3D・深度バッファ)で描きます。画面の文字(TextRenderer)は Direct2D で最後に画面へ重ねるので、3D の物の後ろには隠れません。壁に貼る・物に隠れる文字は WorldTextRenderer を使います。
    • 向き: 板の正面は -Z 側(SpriteRenderer のビルボードと同じ)。位置・向き・大きさは、オーナーの transform(親子込み)。align が Left なら板の左端、Right なら右端がオーナーの位置、Center は板の中心です。
    • ビルボード: SetBillboard(true) でオーナーの回転を使わず、いつもカメラ(CameraShake 込み)の方を向きます。transform.rotate.z だけは板の中の回転になります。
    • 大きさ: 板の大きさ = テクスチャのピクセル数 ÷ SetPixelsPerUnit。例: 64 ピクセルの文字は、既定で高さ 32 ワールド。transform.scale でさらに拡大縮小できます。テクスチャは 2048 ピクセルまでで、超える文字は 見た目の大きさを変えずに細かさを下げ、出力ウィンドウに知らせます。
    • 半透明と描く順番: 文字のふちのなめらかさ(アンチエイリアス)を保つため、半透明で重ね、深度には書きません(物の後ろには隠れますが、後ろの物は隠しません)。そのため 壁などの不透明な物より後に描く 必要があり、Init でオーナーの drawPriority が 0 なら 10 にします(変えたい時は GetOwner()->SetDrawPriority())。背景が不透明(SetBackground の a=1、文字の濃さ 1)なら、深度にも書くふつうの板になります。
    • テクスチャの共有: 文字・フォント・ピクセルの大きさ・太字・色・縁取り・寄せ方・背景・テクスチャの大きさ(絵を決める設定)が すべて同じなら、板が何枚あってもテクスチャは 1 枚 です。板の大きさ・向き・ビルボード・光・両面は絵に関係しないので、共有を妨げません。同じ看板を 100 枚並べても 1 枚分のメモリです。
    • 文字や見た目を変えた時: 共有テクスチャは作ったあと 書き換えません。変えると、今のテクスチャを手放し(借りている数を 1 減らす)、新しい設定のテクスチャを借りに行きます(あれば共有、無ければ新しく描く)。ほかの看板の文字は変わりません。借りている数が 0 になったテクスチャは すぐ解放 されます(シーンを出た時も、Engine の終了時も)。
    • 制限: 毎フレーム変わる文字(カウントなど)は共有されず、変わるたびに新しいテクスチャを描く(Direct2D で描いて GPU に送る)ので重くなります。数字が変わった時だけ SetText を呼びます(同じ文字なら何もしません)。共有のテクスチャが 256 枚を超えると、出力ウィンドウに 1 回知らせます(止めはしません)。
    • 日本語を使う時は Text::LoadFont で読んだフォント名を style.fontName に入れます(TextRenderer と同じ)。影は落とさず・受けません。
