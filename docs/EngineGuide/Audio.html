    Audio(音)

    Engine/Audio/ は音を鳴らす仕組みです(XAudio2 を使用)。鳴らし方は 3 通りあります。
    このページのファイル
    • Audio.h / Audio.cpp
    • AudioSourceComponent.h / AudioSourceComponent.cpp
    • AudioListenerComponent.h / AudioListenerComponent.cpp

    1. Audio::Load → Play(ID で鳴らす): 長く鳴らす BGM 向け。 / 2. Audio::PlayOneShot / PlayOneShotAt(鳴らしっぱなし): 効果音(SE)向け。重ねて鳴らせて、鳴り終われば自動で片付く。 / 3. AudioSourceComponent(物に付ける音): 音を出す物(敵・焚き火など)に付ける。位置で聞こえ方が変わる。

    音のグループ(AudioGroup::BGM / SE)ごとに音量を変えられます(SetGroupVolume)。音は WAV ファイルだけ 読み込めます。

    Demo で見る: Demo プロジェクトの Audio カテゴリに、Sound(BGM・SE・音量グループ・フェード)と Sound3D(位置で聞こえ方が変わる音)の 2 個のデモがあります。

    Engine/Audio/Audio.h Engine/Audio/Audio.cpp

    音の窓口です。BGM を ID で鳴らす関数、効果音を鳴らしっぱなしにする関数、グループごとの音量があります。

    ID で鳴らす(BGM 向け)

    名前引数・戻り値何をするか
    Load(const std::wstring& filepath, bool loop, AudioGroup group)unsigned intWAV を読んで ID を返す。loop の既定は false、group の既定は BGM
    Play(unsigned int id, float volume)void再生する(volume の既定は 1)
    Stop(unsigned int id)void停止する
    Pause(unsigned int id)void一時停止する
    Resume(unsigned int id)void再開する
    SetVolume(unsigned int id, float volume)voidその音の音量
    SetLoop(unsigned int id, bool loop)voidループするかを変える
    Release(unsigned int id)voidその音を削除する
    ReleaseAll()voidすべて削除する

    鳴らしっぱなしの効果音

    名前引数・戻り値何をするか
    PlayOneShot(const std::wstring& path, float volume)void位置に関係なく鳴らす(UI の音など)
    PlayOneShotAt(const std::wstring& path, XMFLOAT3 position, float volume)voidその場所で鳴らす。聞く位置からの距離で小さくなり、左右で聞こえる向きが変わる

    グループの音量

    名前引数・戻り値何をするか
    SetGroupVolume(AudioGroup group, float volume)voidグループの音量(0〜1。範囲外は収める)
    GetGroupVolume(AudioGroup group)floatグループの音量

    定数

    名前引数・戻り値何をするか
    maxVoicesconstexpr int同時に鳴らせる数の上限(32)
    defaultMinDistanceconstexpr floatこの距離までは最大音量(300)
    defaultMaxDistanceconstexpr floatこの距離で聞こえなくなる(2500。その間は直線的に小さくなる)

    内部用(GameEngine・Resources・AudioListenerComponent・AudioSourceComponent だけが呼ぶ)

    名前引数・戻り値何をするか
    Init() / Uninit() / Update()bool / void初期化・終了・毎フレームの更新(鳴り終わった再生口を返す)
    LoadWave(const std::wstring& filepath) / ReleaseWave(unsigned int waveID)unsigned int / void音の波形データの読み込み・解放(Resources::LoadSound が呼ぶ)
    SetListener(position, front, up)void聞く位置と向きを伝える(AudioListenerComponent が呼ぶ)
    StartVoice(waveID, params) / UpdateVoice(handle, params) / StopVoice(handle) / IsVoicePlaying(handle)VoiceHandle / void / bool再生口を借りて鳴らす・変える・止める・鳴っているか
    VoiceHandle / VoiceParamsstruct再生口の借り番号 / 鳴らす時の設定(音量・ループ・位置・距離・グループ)
    使い方の例 出典: Sample2D/Game/Components/TitleController.cpp:18-26
    // 音量の適用(BGM・効果音とも前に設定した値。保存されていなければ最大。Sample2DとSample3Dで同じ設定を使う)
// グループの音量なので、ここで決めれば、ゲーム画面の効果音(PlayOneShotAt)にも効く
volume = Math::Clamp(SaveData::GetFloat(musicVolumeKey, 1.f), 0.f, 1.f);
Audio::SetGroupVolume(AudioGroup::BGM, volume);
Audio::SetGroupVolume(AudioGroup::SE, Math::Clamp(SaveData::GetFloat(soundEffectVolumeKey, 1.f), 0.f, 1.f));

// BGMの再生(BGMグループなので、音量はグループ音量で決まる)
audioID = Audio::Load(L"Assets/TitleBGM.wav", true);
Audio::Play(audioID);
    使い方の例 出典: Sample2D/Game/Components/BulletManager.cpp:48-49
    // 発射音(その場所で鳴らす。連射しても重なって鳴る)
Audio::PlayOneShotAt(L"Assets/Sounds/shot.wav", position);
    気を付ける点
    • WAV ファイルだけ 読み込めます。音が鳴らない時は、WAV の中身(形式)を疑います(README §21)。
    • Audio::Load の音は Release で返すのを忘れずに(シーンの Uninit で)。PlayOneShot は鳴り終われば自動で片付きます。
    • 同時に鳴らせるのは 32 個までです。超えた分は鳴らされず、出力ウィンドウに 1 回知らせます。
    • 同じファイルは Resources で 1 回だけ読み込まれます(2 回目以降は読み直さない)。
    • PlayOneShotAt の「聞く位置」は AudioListenerComponent の位置です。無ければ 2D カメラの位置です。
    • ポーズ中も音は止まらず 鳴り続けます。
    • 音量を保存したい時は SaveData に書きます(Sample の TitleController が実例)。

    Engine/Audio/AudioSourceComponent.h Engine/Audio/AudioSourceComponent.cpp

    音を鳴らす側を表す Component です。音を出す物(敵・機械・焚き火など)に付けます。Unity の AudioSource と同じです。位置で聞こえ方が変わります(遠いほど小さく、左にあれば左から聞こえる)。

    名前引数・戻り値何をするか
    AudioSourceComponent(const std::wstring& path)コンストラクタ鳴らす音のファイル(WAV)
    Play()void最初から鳴らす(鳴っていれば鳴らし直す)
    Stop()void止める
    IsPlaying()bool鳴っているか(ループしない音が鳴り終わったら false)
    SetVolume(float newVolume)void音量(0〜1)
    SetLoop(bool enabled)void繰り返すか(次の Play から)
    SetSpatial(bool enabled)void位置で聞こえ方を変えるか(false = BGM・UI の音)
    SetDistance(float newMin, float newMax)voidnewMin までは最大音量、newMax で聞こえなくなる
    SetGroup(AudioGroup newGroup)void音量を変えるグループ(次の Play から。既定は SE)
    Init() / Update(float dt) / Uninit() / OnActiveChanged(bool active)void (override)内部の処理
    使い方の例 出典: Demo/Game/Objects/Audio/SoundDemo.cpp:31-39
    // BGM: ループする音。位置は使わず(SetSpatial(false))、グループは BGM
auto* bgm = demo->AddComponent<AudioSourceComponent>(L"Assets/TitleBGM.wav");
bgm->SetGroup(AudioGroup::BGM);
bgm->SetSpatial(false);
bgm->SetLoop(true);

// SE: 1回鳴る音。グループは SE(既定)
auto* hit = demo->AddComponent<AudioSourceComponent>(L"Assets/Sounds/hit.wav");
hit->SetSpatial(false);
    気を付ける点
    • SetActive(false) になると止まります(ObjectPool に返した時など)。自動では再開しない ので、必要なら Play し直します。
    • SetLoop と SetGroup は 次の Play から 効きます。SetVolume / SetDistance / SetSpatial は鳴っている間でも変えられます。
    • 同じ音のデータ(WAV)は Resources で共有されます。GameObject を破棄すると、鳴りっぱなしの音は残りません(再生口を返します)。
    • ポーズ中も止まりません。

    Engine/Audio/AudioListenerComponent.h Engine/Audio/AudioListenerComponent.cpp

    音を「聞く側」を表す Component です。Player(かカメラ)に 1 つだけ付けます。Unity の AudioListener と同じです。付けたオブジェクトのワールド位置が「聞く位置」になります。

    名前引数・戻り値何をするか
    SetUse3DCamera(bool enabled)void向きを 3D 用カメラ(Image::GetCamera3D())に合わせる(3D ゲーム用)。位置はいつもこのオブジェクトの位置
    Init() / Update(float dt) / Uninit() / OnActiveChanged(bool active)void (override)内部の処理
    使い方の例 出典: Sample3D/Game/Objects/Player.cpp:33-34
    // 音を聞く位置(Playerの位置で、向きは3D用カメラに合わせる)
player->AddComponent<AudioListenerComponent>()->SetUse3DCamera(true);
    気を付ける点
    • 2D では付けるだけで、画面の上が正面・右が右(向きは固定)です。3D では SetUse3DCamera(true) でカメラの向きで聞きます。
    • 2 つ以上ある時は、最後に有効になった 1 つだけが使われます(出力ウィンドウで 1 回知らせます)。
    • 1 つも無い時は、2D カメラの x, y が聞く位置 になります。2D ゲームは付けなくても動きますが、3D ゲームは付けないと 2D カメラの位置で聞いてしまう ので、必ず Player などに付けます。
    • 非アクティブの間と、破棄された後は聞く位置になりません。
