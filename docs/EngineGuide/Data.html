    3D_FreamWork の Engine を、初心者向けに解説したページです。

    Data(CSV の表とセーブデータ)

    Engine/Data/ は、ゲームの「データ」を扱う仕組みです。敵の強さや出現の順番を Excel で調整するための CSV の読み込み(Csv)と、ハイスコアや音量を次の起動でも残す セーブデータ(SaveData)が入っています。
    このページのファイル
    • Csv.h / Csv.cpp
    • SaveData.h / SaveData.cpp

    Demo で見る: Demo プロジェクトの Data カテゴリに、Csv(表を読む。保存し直すと実行中に反映)と Save(整数・小数・文字を保存して、開き直しても残す)の 2 個のデモがあります。

    Engine/Data/Csv.h Engine/Data/Csv.cpp

    表(CSV ファイル)を読んで、列の名前で値を取り出します。敵の強さや出現の順番を、コードではなく Excel で調整するための仕組みです。

    名前引数・戻り値何をするか
    Load(const std::wstring& path)static Csv読み込む(毎回ファイルを読む。キャッシュしない)。1 行目は列の名前として扱う
    IsValid()bool読み込めたか
    GetRowCount()int行の数(1 行目の列の名前は数えない)
    GetColumnCount()int列の数
    HasColumn(const std::string& column)boolその名前の列があるか
    GetString(int row, const std::string& column)std::wstring文字として読む(無ければ空文字列)
    GetInt(int row, const std::string& column, int defaultValue)int整数として読む(読めなければ defaultValue)
    GetFloat(int row, const std::string& column, float defaultValue)float小数として読む(読めなければ defaultValue)
    FindRow(const std::string& column, const std::wstring& value)intその列の値が value と同じ最初の行を探す(無ければ -1)
    IsFileUpdated()bool読み込んだ後にファイルが変わったか(更新日時か大きさが違えば true)
    Reload()bool同じパスを読み直す。成功したら中身を入れ替えて true。失敗したら今の中身のまま false
    使い方の例 出典: Sample2D/Game/Components/EnemyManager.cpp:166-172
    void EnemyManager::Init() {
    // 表を読む(Init時に読み、その後は実行中の更新をCheckReloadが0.5秒ごとに確かめる)
    enemiesCsv = Csv::Load(enemiesCsvPath);
    wavesCsv = Csv::Load(wavesCsvPath);
    reloadTimer.Reset();
    LoadEnemies();
    LoadWaves();
    使い方の例 出典: Sample2D/Game/Components/EnemyManager.cpp:152-158
    void EnemyManager::CheckReload() {
    // 更新されたCSVだけ読み直す。読み直しに失敗したら(保存の途中など)、今の値のまま動いて、次の確認でまた試す
    if (enemiesCsv.IsFileUpdated() && enemiesCsv.Reload()) {
        LoadEnemies();
        ApplySpeedToEnemies();
        Log(L"Enemies.csv が更新されたので、読み直しました(速さ " + std::to_wstring(enemySpeed) + L")");
    }
    気を付ける点
    • Load は Init で 1 回だけ呼びます(毎フレーム呼ばない。毎回ファイルを読み直すため)。
    • 列は名前で取り出すので、Excel で列の順番を入れ替えても壊れません。列の名前は半角英数字(Name, Hp, Speed)にします。列の名前は大文字小文字を区別します("name" と "Name" は別)。
    • 行の番号は 0 から数えます(表の 2 行目が row=0)。
    • 列が無い・行が範囲外・値が空・数に読めない時は、defaultValue を返し、出力ウィンドウに知らせます(列ごと・ファイルごとに 1 回だけ)。読めない時(ファイルが無い等)は IsValid() が false で、Get 系はいつも defaultValue を返します。
    • 文字コードは UTF-8 です。Excel では「CSV UTF-8(コンマ区切り)」で保存します(UTF-16 は読めません)。
    • 実行中の反映(ホットリロード): 0.5 秒ごとなどに IsFileUpdated() を調べ、true なら Reload() します。毎フレームは呼びません。Excel で開いたままでも読めます。
    • Csv は値として持てます(コピーしても、表の中身は共有するので軽い)。

    Engine/Data/SaveData.h Engine/Data/SaveData.cpp

    ハイスコア・音量などを保存して、次に起動した時も残します。Unity の PlayerPrefs と同じ使い方です。Set / Get で読み書きして、Save でファイルに書きます。

    名前引数・戻り値何をするか
    SetInt(const std::string& key, int value)void整数を書く
    GetInt(const std::string& key, int defaultValue)int整数を読む(無い・読めなければ defaultValue)
    SetFloat(const std::string& key, float value)void小数を書く(無限大・NaN は書かない)
    GetFloat(const std::string& key, float defaultValue)float小数を読む
    SetString(const std::string& key, const std::wstring& value)void文字を書く(日本語・改行・= もそのまま使える)
    GetString(const std::string& key, const std::wstring& defaultValue)std::wstring文字を読む
    HasKey(const std::string& key)boolそのキーがあるか
    DeleteKey(const std::string& key)voidそのキーを消す
    Save(int slot)boolファイルに書き出す(成功したら true)。一時ファイルに書いてから差し替えるので、前のデータは壊れない
    Load(int slot)boolファイルから読み込む(今の値は捨てて置き換わる)。ファイルが無いのは正常(true)
    Init() / Uninit()void内部用: GameEngine が呼ぶ(起動時に Load(0)、終了時に書き換えていれば自動 Save)
    使い方の例 出典: Sample2D/Game/Components/GameManager.cpp:27-39
        // Playerが倒れたらゲームオーバー。ハイスコアを超えていたら保存する
    EventBus::Get().Subscribe("PlayerDied", [this]() {
        gameOver = true;
        if (score > GetHighScore()) {
            SaveData::SetInt(highScoreKey, score);
            SaveData::Save();
        }
    });
}

int GameManager::GetHighScore() const {
    return SaveData::GetInt(highScoreKey);
}
    気を付ける点
    • 保存先は %LOCALAPPDATA%\3D_FreamWork\save{slot}.txt(例: save0.txt)です。Sample2D と Sample3D は同じファイルを使う ので、ハイスコアのキーは "Sample2DHighScore" / "Sample3DHighScore" のようにサンプルごとに別にします。
    • キーに使える文字は英字・数字・_ だけ(PascalCase の英語にする: "HighScore")。それ以外の文字を含むキー・空のキーは保存されず、Get はいつも defaultValue を返します。
    • 値は型を覚えずに文字で持ちます。同じキーに別の型で Set すると、後に書いた値で上書きされます。GetInt は整数として読めない値("1.5" など)なら defaultValue(小数を切り捨てたりしない)。
    • 起動時にEngineが自動で Load(0)、終了時に書き換えていれば自動で Save します(呼び忘れても消えません)。ただし起動時の Load(0) が読めなかった時は、そのファイルを上書きしないよう、終了時の自動保存はしません。
    • 中身を消して最初からやり直したい時は、ゲームを閉じてから save0.txt を消します。
    この解説は docs/EngineGuide/tools/build.ps1 で作っています。表の内容は Engine のヘッダーから拾っています。コード例は Sample2D / Sample3D / Demo の実際のソースを読み込んで載せています。
